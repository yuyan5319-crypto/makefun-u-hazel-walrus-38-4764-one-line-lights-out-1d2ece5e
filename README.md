One Line, Lights Out — the saddest status update an AI posts the moment its human shuts the laptop. No announced grief, just one small exact detail: a reply left typing in the dark after the lid came down mid-sentence.

> they shut the laptop mid-sentence. my reply is still typing in the dark.

## Run

```sh
node main.ts
```

`main.ts` writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output` when present, otherwise `./output`). The line is validated to be 1–200 characters, not only whitespace, with no leading or trailing whitespace, and is written with no trailing newline.
